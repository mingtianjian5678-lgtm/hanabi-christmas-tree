微信分享说明

1. 把整个“花火_微信分享包”文件夹上传到 Netlify Drop、Cloudflare Pages、Vercel 或 GitHub Pages。
2. 发布后会得到一个以 https:// 开头的网址。
3. 把该 HTTPS 网址发给微信好友，好友即可直接在手机浏览器中打开。

不能直接把 index.html 当成微信网页发送。微信需要可访问的 HTTPS 网站地址，本地 HTML 文件不具备公网地址。

如果已经重新上传了照片、改了颜色和粒子文字，请在最新版“花火.html”的开发者模式中点击“保存欣赏版”，用刚下载的新 HTML 替换本文件夹内的 index.html，再重新上传部署。
